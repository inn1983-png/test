最终版 UI 结构

1. 首页：项目生产总览

展示项目、章节、当前模块、整体进度、失败阻塞、最新产物。用户一眼知道系统跑到哪一步。

2. 生产控制台

支持粘贴小说、选择 project/book_chapter、从某模块继续、只重跑某模块、本地 LLM 参数、后续 ComfyUI/TTS/视频参数。

3. 阶段透明区

每个模块独立展开：阶段目标、LLM 是否运行、原始输出、JSON 修复、评分、修改意见、重跑次数、总检结果。

4. 资产库工作台

03/04/05 不再只是 JSON 文件，而是可视化角色卡、场景卡、道具卡。后续 07 可在这里绑定定妆照、造型照、场景参考图、道具参考图。

5. 分镜工作台

06 输出帧序列、角色引用、costume_id、appearance_asset_key、连续性说明、四宫格预览组。后续 07 图片出来后变成图文分镜表。

6. 媒体生产区

07 图片、08 音频、09 视频、10 合成会有独立队列、预览、失败重试、显存资源状态和最终导出。

7. 返工中心

把所有 needs_retry、upstream_blocking_issues、schema_validation_issues 集中展示，用户可以一键从最早问题阶段重跑。
